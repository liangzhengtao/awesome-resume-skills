# Contributing to Awesome Resume Skills

Thank you for your interest in contributing! This project aims to help everyone create better resumes.

## How to Contribute

### Adding a New Skill

1. Fork the repository
2. Create a branch: `git checkout -b add-skill/your-skill-name`
3. Create the skill file in the appropriate category folder
4. Follow the skill file template structure (see below)
5. Submit a pull request

### Skill File Structure

Every skill file should include these sections:

```markdown
# [Skill Name]

> One-line description.

## When to Use
- Bullet list of trigger scenarios

## Framework
- Structure, rules, and guidelines

## Templates
- Fill-in-the-blank templates

## Examples
- Before & After comparisons

## Common Mistakes
- Numbered list of pitfalls

## 中文版本
- Chinese version of key points
```

### Minimum Requirements

- **150+ lines** per skill file
- Must include: When to Use, Framework, Templates, Examples, Common Mistakes
- Must include a 中文版本 section at the end
- Templates must be fill-in-the-blank (not just descriptions)
- Examples must include before/after comparisons

### Improving Existing Skills

- Fix typos or broken formatting
- Add new templates or examples
- Update outdated information
- Improve clarity of instructions

### Reporting Issues

- Use the [Bug Report](../../issues/new?template=bug_report.md) template for errors
- Use the [Feature Request](../../issues/new?template=feature_request.md) template for suggestions

## Style Guidelines

- Use Markdown headers (`#`, `##`, `###`) for structure
- Use tables for comparisons and structured data
- Use code blocks for templates and examples
- Use `>` blockquotes for important notes
- Keep line length reasonable (80-100 chars where practical)
