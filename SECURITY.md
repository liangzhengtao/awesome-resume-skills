# Security Policy

## Reporting a Vulnerability

This project contains educational content (Markdown files). If you find any issues:

### Content Issues
- Inaccurate advice or outdated information
- Broken links or references
- Formatting errors

Please open a [Bug Report](../../issues/new?template=bug_report.md) issue.

### Security Concerns

If you find a security concern (e.g., a link pointing to a malicious site), please email the maintainer directly rather than opening a public issue.

**Do not** open a public issue for security vulnerabilities.

## Response Timeline

- Content issues: Addressed within 7 days
- Security concerns: Acknowledged within 48 hours

## Scope

This project is a collection of Markdown files. It does not:
- Execute any code
- Collect user data
- Connect to external services
- Process sensitive information
