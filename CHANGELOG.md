# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - 2024-01-01

### Added

#### 传统简历 (Traditional Resumes)
- **Professional Resume** — ATS-friendly corporate resume with corporate, consulting, and finance templates
- **Academic CV** — Complete CV for researchers and professors with APA/IEEE formatting
- **Federal Resume** — Extended government resume with KSA templates and USAJobs format

#### 创意简历 (Creative Resumes)
- **Infographic Resume** — Visual resume with data visualization, timeline, and dashboard templates
- **Portfolio Resume** — Resume with embedded project showcases for developers and designers
- **Video Resume** — Video script and production guide with 60-second and 3-minute templates

#### 技术简历 (Technical Resumes)
- **Software Engineer** — SWE resume for Junior/Mid/Senior/Staff levels
- **Data Scientist** — DS/ML engineer resume with model metrics and publication guidelines
- **DevOps Engineer** — DevOps/SRE/Cloud Architect resume with infrastructure metrics

#### 求职优化 (Job Search Optimization)
- **ATS Optimization** — Keyword extraction, formatting rules, and ATS system guides
- **Cover Letter** — Opening hooks, templates for cold/referral/career-change applications
- **LinkedIn Optimization** — Profile SEO, headline formulas, networking messages

#### Community Files
- README.md and README.zh.md (bilingual)
- Banner SVG with gradient design
- MIT License
- Contributing guidelines
- Code of Conduct
- Security policy
- GitHub issue templates
- Pull request template
- CI workflow
