# Professional Resume Skill

> Clean, ATS-friendly resume for corporate and traditional business roles.

## When to Use

- Applying to Fortune 500 companies, banks, consulting firms
- Roles in finance, accounting, operations, HR, marketing
- When the job posting mentions "traditional resume format"
- When you need maximum ATS compatibility

## Framework

### Standard Sections (in order)

1. **Header** — Name, phone, email, LinkedIn, city/state (no full address)
2. **Professional Summary** — 2-3 lines, role + years + key achievements
3. **Experience** — Reverse chronological, 3-5 bullet points per role
4. **Education** — Degree, school, graduation year, GPA (if >3.5)
5. **Skills** — Grouped by category (Technical, Languages, Certifications)

### Formatting Rules

| Element | Guideline |
|---------|-----------|
| Font | Calibri, Garamond, Cambria, or Helvetica (10-12pt) |
| Margins | 0.5" to 1" on all sides |
| Spacing | 1.15 line spacing, 6pt after paragraphs |
| Length | 1 page (0-10 yrs exp), 2 pages (10+ yrs) |
| File format | PDF unless ATS requires .docx |

### Bullet Point Formula

```
[Action Verb] + [What You Did] + [Measurable Result] + [Context/Scale]
```

## Examples

### Before & After: Experience Section

**Before (weak):**
```
Marketing Manager at Acme Corp
- Was responsible for social media
- Helped with campaigns
- Worked on email marketing
```

**After (strong):**
```
Acme Corp — Senior Marketing Manager | 2021 – Present
• Orchestrated multi-channel campaigns reaching 2.4M users, driving 34% YoY revenue growth
• Grew social media following from 12K to 185K in 18 months through content strategy overhaul
• Designed A/B testing framework for email campaigns, improving open rates from 18% to 29%
```

## Common Mistakes

1. **Using "Responsible for"** — Start bullets with strong action verbs instead
2. **Listing duties instead of achievements** — Focus on impact, not tasks
3. **Including references or "References available upon request"** — Remove entirely
4. **Using personal pronouns (I, my, we)** — Omit subject, start with verb
5. **Unexplained employment gaps** — Address briefly in cover letter
6. **Creative fonts or colors** — Stick to standard professional fonts
7. **Photo on resume** — Remove for US/UK/Canada (include for EU/Asia if customary)

## ATS Optimization Checklist

- [ ] Use standard section headings (Experience, Education, Skills)
- [ ] Avoid tables, text boxes, headers/footers for critical info
- [ ] Use standard bullet points (• or -)
- [ ] Include keywords from job description naturally
- [ ] Save as PDF unless .docx specifically requested
- [ ] Test with [JobScan](https://www.jobscan.co/) or similar tool

## 中文版本

### 适用场景

- 申请世界500强、银行、咨询公司
- 金融、会计、运营、人力资源、市场等岗位
- 职位描述明确要求"传统简历格式"
- 需要最大化ATS系统兼容性时

### 格式要点

- **字体**：宋体（正文）、黑体（标题），英文用Calibri或Garamond
- **页边距**：上下2.5cm，左右2-3cm
- **篇幅**：应届生1页，资深人士2页
- **照片**：国内简历建议放正装照

### 经验描述公式

```
【动词】+【做了什么】+【量化成果】+【规模/背景】
```

### 常见问题

1. 罗列职责而非成果 — 重点写成绩和影响
2. 信息过多 — 不需要写身份证号、籍贯（除非要求）
3. 自我评价空洞 — 用具体数据支撑
4. 时间格式不统一 — 统一用"YYYY.MM"格式
