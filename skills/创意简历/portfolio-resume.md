# Portfolio Resume Skill

> Resume integrated with portfolio showcasing projects, code, and design work.

## When to Use

- Software developers applying to tech companies
- UX/UI designers with visual work to showcase
- Data scientists with notable projects
- Freelancers and contractors demonstrating capabilities
- When job posting asks for "portfolio" or "work samples"

## Framework

### Portfolio Resume Structure

1. **Hero Section** — Name, title, one-line value proposition
2. **Featured Projects** — 3-5 best projects with full write-ups
3. **Skills Section** — Grouped by category with proficiency indicators
4. **Experience** — Traditional format but with project links
5. **Education & Certifications**
6. **Contact & Links** — GitHub, LinkedIn, personal site

### Project Showcase Format

Each project should include:
- **Title & Role** — What you built, what was your role
- **Problem** — What challenge did it solve
- **Tech Stack** — Languages, frameworks, tools
- **Key Contributions** — Your specific contributions
- **Impact** — Metrics, users, outcomes
- **Link** — GitHub repo, live demo, or case study

## Image Optimization Guidelines

| Use Case | Format | Max Size | Dimensions |
|----------|--------|----------|------------|
| Hero screenshot | WebP/PNG | 200KB | 1200×800px |
| Project thumbnail | WebP/JPG | 100KB | 600×400px |
| Code snippet | PNG | 50KB | 800×auto |
| Full case study | WebP | 500KB total | 1400px wide |

## Common Mistakes

1. **Too many projects** — Quality over quantity; 3-5 strong projects beat 15 mediocre ones
2. **No context** — Explain WHY you built it, not just WHAT
3. **Missing metrics** — "Increased performance" → "Reduced load time from 3.2s to 0.8s"
4. **Broken links** — Test every link before sharing
5. **Huge images** — Optimize for web; nobody waits for 5MB screenshots
6. **Only code, no explanation** — Non-technical reviewers read these too
7. **Forgetting mobile** — Many recruiters review on phones
8. **No personal projects** — Shows intrinsic motivation and curiosity

## 中文版本

### 适用场景

- 软件开发工程师申请科技公司
- UX/UI设计师展示视觉作品
- 数据科学家展示项目成果
- 自由职业者和承包商展示能力

### 中文作品集简历要点

- **项目描述**：先写业务背景，再写技术方案
- **代码展示**：GitHub链接是必须的，确保README写得好
- **设计作品**：使用站酷、Behance等平台托管作品集
- **图片优化**：国内网络环境更注意加载速度

### 推荐平台

- 代码：GitHub、Gitee
- 设计：站酷、UI中国、Behance
- 综合：个人博客（推荐用Hugo/Hexo搭建）
