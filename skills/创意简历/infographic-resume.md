# Infographic Resume Skill

> Visual resume using charts, timelines, icons, and data visualization.

## When to Use

- Applying for design, UX, marketing, or creative roles
- When the company culture emphasizes creativity (startups, agencies)
- As a supplement to a traditional resume (not a replacement)
- Networking events, personal websites, portfolio presentations

**WARNING:** Infographic resumes are generally NOT ATS-friendly. Always submit a standard text resume through ATS systems and send the infographic version directly to hiring managers or via email.

## Framework

### Visual Elements

1. **Header** — Name in large type, tagline, contact icons
2. **Skills Radar Chart** — Visual proficiency levels (beginner to expert)
3. **Experience Timeline** — Horizontal or vertical timeline with key roles
4. **Education Badges** — Degree icons with institution logos
5. **Achievement Metrics** — Big numbers with context
6. **Tools & Technologies** — Icon grid with proficiency bars
7. **Languages** — Globe icon with proficiency indicators
8. **Interests** — Icon-based personal interests

### Design Principles

| Principle | Guideline |
|-----------|-----------|
| Color palette | 2-3 primary colors + neutrals |
| Typography | Max 2 font families (1 heading, 1 body) |
| White space | At least 30% empty space |
| Data-to-ink ratio | Remove every element that doesn't convey information |
| Consistency | Uniform icon style, spacing, and alignment |
| File format | PDF for print, PNG for web, SVG for scaling |

### Color Schemes for Different Industries

```
Corporate/Finance: Navy (#1B3A5C) + Gold (#C9A84C) + White
Tech/Startup: Electric Blue (#2563EB) + Violet (#7C3AED) + Dark Gray
Creative/Design: Coral (#FF6B6B) + Teal (#4ECDC4) + Charcoal
Healthcare: Teal (#0D9488) + White + Light Gray
Education: Forest Green (#166534) + Amber (#F59E0B) + Cream
```

| Figma | Free | Intermediate | Collaborative design |
| Canva | Free/Pro | Beginner | Templates and drag-drop |
| Adobe Illustrator | Paid | Advanced | Full creative control |
| InDesign | Paid | Advanced | Print-ready layouts |
| Piktochart | Free/Paid | Beginner | Infographic focus |
| Venngage | Free/Paid | Beginner | Resume templates |
| PowerPoint/Keynote | Included | Beginner | Quick layouts |

## Common Mistakes

1. **Too much visual clutter** — White space is your friend
2. **Using infographic resume as the only resume** — Always pair with a text version
3. **Inconsistent icon styles** — Pick one icon set and stick with it
4. **Exaggerated skill levels** — Be honest; you'll be tested
5. **Poor color contrast** — Ensure readability (check WCAG guidelines)
6. **Missing contact information** — Don't sacrifice function for form
7. **Overly creative fonts** — Decorative fonts are hard to scan
8. **No clear hierarchy** — Eyes should flow naturally through the content

## 中文版本

### 适用场景

- 设计、UX、市场营销、创意类职位
- 公司文化强调创意的环境（初创、广告公司）
- 作为传统简历的补充（而非替代）
- 社交活动、个人网站、作品集展示

### 信息图表简历注意事项

- **ATS兼容性差**：信息图表简历通常无法被ATS正确解析
- **始终同时提供**：提交ATS时用传统简历，信息图版本直接发给招聘经理
- **设计工具**：推荐使用Figma、Canva、稿定设计等工具
- **色彩搭配**：注意行业特点，金融用深蓝/金色，科技用蓝紫色，创意用珊瑚色/青色

### 中文简历设计要点

- 中文字体推荐：思源黑体、阿里巴巴普惠体、站酷高端黑
- 注意中英文混排的间距和字体搭配
- 竖版排版更适合中文阅读习惯
- 可以加入书法元素增加文化感
